# AI 角色貼圖與一頁式專題網站研習

這是一套兩小時的學生實作課程。學生先把手繪角色轉成九宮格 LINE 貼圖，再用貼圖輔助呈現自己的專題，完成只有兩個 Section 的一頁式網站。

- 第一小時：[九宮格貼圖課堂](https://codinglu.tw/tutorial/line-sticker)
- 第二小時：[GPT 專題網站上架課](https://codinglu.tw/tutorial/line-sticker/site)
- LINE Creators Market：[creator.line.me](https://creator.line.me/zh-hant/)

## 課程目標

學生完成課程後可以：

1. 將手繪草圖整理成外觀一致的原創角色。
2. 使用提示詞請 ChatGPT 產生九宮格貼圖。
3. 手動調整切割線，輸出符合 LINE 尺寸的透明 PNG。
4. 使用架構草圖與互動色相環做出網站設計決策。
5. 請 GPT 產生單一 HTML，並在本地確認桌面與手機畫面。
6. 從八張貼圖中挑選適合專題內容的圖片，完成並上架網站。

## 課前準備

- 學生已在前四小時確定專題主題與想解決的問題。
- 每位學生準備一張手繪角色草圖。
- 網站已內建手繪草圖、角色三視圖與九宮格範例；未上傳自己的圖片時可以直接使用範例操作。
- 第二小時已內建第一堂匯出的八張透明 PNG，未匯入自己的 ZIP 時會以這組貼圖示範網站預覽。
- 可登入 ChatGPT 的帳號與現代瀏覽器。
- 網站製作不直接呼叫 OpenAI API，提示詞會複製後交由 ChatGPT 執行。
- 公開成果不得包含真實全名、班級、住址、電話、帳號密碼或可辨識個人的照片。

## 第一小時：手繪角色到 LINE 貼圖

口號：**用 LINE 貼圖推廣你的專題。**

| 時間 | 教學內容 | 學生產出 |
| --- | --- | --- |
| 00–10 分 | 畫出容易辨識的角色，確認輪廓、表情、服裝與道具 | 手繪角色草圖 |
| 10–25 分 | 在網站整理角色提示詞，複製到 ChatGPT，並上傳草圖 | 同一角色的設定圖或三視圖 |
| 25–40 分 | 上傳角色設定圖，請 ChatGPT 一次產生 3 × 3 九宮格動作 | 九宮格貼圖圖片 |
| 40–60 分 | 拖曳上下左右切割線、選八張、去背與調整尺寸 | LINE 貼圖 ZIP |

### 第一小時操作流程

1. 開啟九宮格貼圖課堂，先查看 LINE Creators Market。
2. 上傳手繪圖並確認角色提示詞；網站只準備提示詞，不消耗 API 額度。
3. 到 ChatGPT 上傳草圖並貼上提示詞，取得角色設定圖。
4. 在同一個對話上傳設定圖，貼上九宮格提示詞。
5. 將九宮格圖片帶回網站，拖曳四條格線對準圖片實際分隔。
6. 選擇八張貼圖，使用瀏覽器工具去背並輸出最大 `370 × 320 px` 的透明 PNG。
7. 分別選擇貼圖小舖主圖與聊天室小圖，下載完整 ZIP。

### LINE 靜態貼圖規格

- 貼圖：8、16、24、32 或 40 張，每張最大 `370 × 320 px`。
- 主圖：1 張，`240 × 240 px`。
- 聊天室小圖：1 張，`96 × 74 px`。
- 格式：PNG、RGB、72 dpi 以上，寬高為偶數。
- 貼圖需透明背景，檔案小於 1 MB，主體邊緣保留約 10 px 安全距離。

## 第二小時：貼圖輔助專題網站

網站成果固定為單一 `index.html`、一頁式、剛好兩個主要 Section。每段約一個畫面高，內容以學生輸入原文為主，GPT 額外增加的中文字合計不得超過 50 字。

| 時間 | 教學內容 | 學生產出 |
| --- | --- | --- |
| 00–20 分 | 填寫專題內容，選擇兩段式架構草圖，以色相環建立配色 | 網站設計決策與提示詞 |
| 20–30 分 | 上傳八張貼圖與提示詞，請 GPT 分析並挑選合適貼圖 | 單一完整 HTML |
| 30–45 分 | 貼回 HTML，匯入貼圖，在桌面、手機、全螢幕或新分頁確認 | 本地網站預覽 |
| 45–60 分 | 下載網站 ZIP，使用 Vercel Drop 上架並以手機複查 | 公開專題網站網址 |

### 第二小時操作流程

1. 輸入專題名稱、問題、讀者與希望呈現的內容。
2. 選擇故事推進、資料說服、成果展示，或上傳自己的架構草圖。
3. 在互動色相環選擇主色與色彩關係，確認五個色票及文字對比。
4. 複製提示詞並開啟 ChatGPT，同時上傳 `01.png` 到 `08.png`。
5. GPT 應逐張分析動作與表情，只使用適合專題語境的貼圖，不必全部放入。
6. 將完整 HTML 貼回本地工具，確認只有兩個 Section，且沒有 Section 內部滾輪。
7. 使用全螢幕或新分頁預覽，分別檢查桌面與手機畫面。
8. 下載 ZIP，前往 [Vercel Drop](https://vercel.com/drop) 拖入檔案並部署。

## 教師引導重點

- 先做內容與版面決策，再請 AI 寫程式，避免直接要求「幫我做一個漂亮網站」。
- 提醒學生固定角色輪廓、比例、五官、服裝、配色與道具，只改動作與表情。
- 九宮格切割線以實際圖片為準，不假設每格尺寸完全平均。
- 貼圖是輔助專題溝通的素材，不是網站主角，也不必八張全部使用。
- 網站若放不下，應精簡內容，不以小字、裁切、第三個 Section 或內層滾輪處理。
- 公開前以手機再次確認文字、圖片、個資與公開網址。

## 本機執行

```bash
vercel dev --listen 8790
```

研習頁面為：

- `http://localhost:8790/tutorial/line-sticker`
- `http://localhost:8790/tutorial/line-sticker/site`

## 專案結構

```text
index.html             # 第一小時：九宮格貼圖課堂
site/                  # 第二小時：一頁式網站課堂
assets/                # 教學示意圖片
vercel.json            # Vercel 靜態網站設定
```
